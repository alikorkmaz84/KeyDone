        Klavye kısayolları

        • Ctrl+F: Arama kutusuna git
        • Ctrl+N: Yeni kayıt
        • Ctrl+E: Açık kaydı düzenle
        • Ctrl+S: Kaydı kaydet (düzenlerken)
        • Ctrl+C: Açık kaydın şifresini kopyala (metin seçili değilken)
        • Ctrl+B: Açık kaydın kullanıcı adını kopyala
        • Ctrl+U: Açık kaydın web sitesini aç
        • Ctrl+G: Şifre üretici
        • Ctrl+L: Kasayı kilitle
        • Delete: Açık kaydı sil (onay istenir)
        • Escape: Geri dön veya pencereyi kapat
        • Aşağı ok, Yukarı ok, Home, End: Kayıt listesinde gezin
        • F1: Bu listeyi aç
